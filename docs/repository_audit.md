# 仓库结构审查与整理决策

> 本页主体保留上一轮整理决策（2026-09-08）；其中删除、修复和并行任务均为历史记录。
> 2026-09-20 没有重复删除这些文件，当前范围/变更/验证见 [本次审计](audit_2026-09-20.md)。

本次先分工阅读了九个 ROS package 的源码、测试、launch、参数、URDF/模型引用、构建与安装规则、已有文档和可用 Git 历史。二进制模型检查文件类型、数量、尺寸、来源记录与散列，未把二进制内容当可读源代码。原始归档、现场捕获与厂商工作区按边界做清单/来源检查，没有自动并入本项目。

## 起始状态

真正 Git 根是 `arm_ws`，父目录还有独立厂商工作区、历史交接、CAD 与生成产物，不是一个可以直接公开的单仓库。Git main 只有 `dbe13bb`（工作区快照）和 `b306629`（夹爪/预览集成），无 remote；当前功能显著超出 HEAD，许多新包未被追踪。

同时存在活动的 RGB-D 视觉重构任务。当前文档根据磁盘最新实现编写，本次没有回滚或覆盖其算法、控制器、CAD 运动模型、场景配置或实验记录。发布工具使用逐文件快照和散列，后续核心变更必须重新审查/导出。

## 最小结构整理

保持标准 `src/<ROS package>`，资源放对应包内，避免搬动 `package://` 引用。新增 `scripts` 提供公共操作入口，`config/examples` 提供显式参数示例，`docs` 统一当前文档，`models`/`assets` 说明资源与授权，`tools/release` 管理审计/候选导出。

旧根脚本的固定三工作区布局不再是新用户推荐路径，保留给现有部署。旧 Astra 抓取与新 `visual_grasp` 别名不兼容，保留实现和回归证据，列为技术债，不编造“可用 demo”。旧 AprilTag 模块仍承担标定、历史回归与诊断，不能直接删除。

## 删除与保留

只删除 47 个经 AppleDouble 格式签名确认的 `._*` 元数据文件，共 192,512 bytes。删除前逐项备份并验证 SHA-256，可从本地独立备份恢复。没有删除任何功能源码。

移除一个无效 console entry point：`joint_mapping:main` 并不存在；数学模块及所有调用保留。移除 CMake 中不存在的 `dummy-v2-mirror-test.urdf` 检查输入，保留当前真实 URDF 检查。

旧 `dummy-v1` mesh 仍被旧 URDF 引用，不删除。src.zip、恢复备份、bags、artifacts 是历史/现场证据，仅忽略并排除公开导出；不能当作普通缓存批量删除。

## 工程问题与处理

修复 std_msgs、rviz2、OpenCV/tf2_msgs 等已证明缺失的依赖声明；补充实际用途描述，移除私人维护邮箱。安装规则排除 `__pycache__`。新增脚本不再要求作者家目录或固定相邻 vendor 布局。`arm_feedback_safe` 只更正错误安全文案，原行为保持；没有将“safe”名称当成禁止运动的证据。

未做大规模格式化、节点重写、关节映射配置化、自动驱动解锁、硬件限位调整或标定值替换。硬件边界及单独变更记录见 [hardware_changes.md](hardware_changes.md)。

## 技术债优先级

- 发布与复现：模型来源/许可、固件/BOM/接线缺失，依赖尚非全平台锁定。公开邮箱已于 2026-09-21 确认；URL 与最新门禁见 [发布清单](../RELEASE_CHECKLIST.md)。
- 兼容迁移：旧 Astra preview validator 与新入口协议不同，旧 J6/被动关节检查过时。
- 反馈可靠性：普通 MOVE ACK 不等于到位；夹爪缺位置/力反馈、完整重连与显式串口关闭。
- 标定：采样专项测试不足，部分历史文件 schema 的缺失/负数质量指标校验可加强；不在活动核心上插入不协调的行为变更。
- 可维护性：驱动/GUI bridge 较大，存在旧日志和格式债；先建立回归边界再按职责拆分。

最终检查数字、公开候选范围及可执行下一步见 [RELEASE_READINESS.md](RELEASE_READINESS.md)。
