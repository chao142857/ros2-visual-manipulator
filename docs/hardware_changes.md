# 硬件行为变更记录

本文件把公开发布整理与已有硬件实现区分开。此次工作开始时，工作区已有未提交的驱动、
GUI、URDF、视觉与 CAD 改动；这些既有改动不能全部归因于本次整理。
发布时应结合最终 [Release Readiness Report](RELEASE_READINESS.md) 和实际差异审查。

## 本次整理的边界

本轮不调整关节方向、零位、电机映射、关节物理范围、夹爪 PWM 允许范围、速度/加速度或停机协议。
原有视觉/CAD 工作保留在本地，公开导出中的许可过滤不构成对实机模型的修改。
文档不授予新的硬件能力，也不把历史校准改成已完成的物理验收。

以下是需要保持的当前基线：

| 契约 | 当前值/行为 | 本轮处理 |
| --- | --- | --- |
| 六轴 raw/ideal 映射 | raw 参考 `[0,-75,180,0,0,0]°`；ideal 参考 `[0,75,-90,0,0,0]°`；方向 `[-1,-1,-1,1,1,1]` | 保留实现，公开记录 |
| J1–J5 默认软件范围 | `[-3.14,3.14] rad` | 保留；注明机械范围尚需实物核实 |
| J6 | V2 模型 continuous；驱动不限制有限位置值 | 保留；记录 GUI 多圈编辑限制及线缆约束 |
| 速度 | 普通 30，LIVE 10，LIVE 上限 20 | 保留；不把协议参数包装成经过标定的末端速度 |
| START / MOVE ACK | START 确认后才能发送首条正常 MOVE；入队 ACK 不等于完成 | 保留；补充协议语义 |
| STOP / DISABLE | 原时间戳屏障、ACK、LIVE 退出与卸力语义 | 保留；明确与硬件急停的区别 |
| LIVE FOLLOW | 心跳、反馈新鲜度、每轴步长、FIFO 压力与不自动重启 | 保留 |
| 夹爪 | OPEN 600、CLOSE 1300、允许 600–1700 μs、默认 600 ms | 保留；纠正文档把 close 预设与上限混为一谈的问题 |
| 动态 TCP | 历史 100–131.5 mm 脉宽表，沿 tool0 −Y 的被动伸长 | 保留；不冒充传感器反馈 |
| CAD/规划验证 | 未确认的安装/开口/TCP/外参字段仍保持未验证 | 保留；不为了让 demo 运行而放开门禁 |

ROS 依赖声明、安装规则、失效的 CLI 注册和文档路径等工程修正不应改变上述运行契约。
若最终审查发现必须改变任一硬件行为，应在合并前新增条目，说明旧值、新值、错误证据、影响和实机复验状态，
而不能将其合并到“清理代码”一项中。

## 公开候选中的设备选择变化

公开候选有两项单独记录的设备选择变化，原硬件工作区不变：相机真实序列号替换为不匹配
实际 D405 的一位占位值；夹爪唯一 USB by-id 路径替换为
`/dev/serial/by-id/CONFIGURE_GRIPPER_PORT`。使用者必须显式配置自己的设备。
这些副本变化不调整关节/PWM/速度或停机协议，逐文件原始行号见公开候选的
`PUBLICATION_TRANSFORMATIONS.json`，详细边界见 [发布审计](../PUBLICATION_AUDIT.md)。

## 审查发现但没有在本轮调整的硬件技术债

1. **GUI 连续 J6 的显示范围。** 后端接受多圈角度，编辑控件仍按配置范围裁切。
   需要围绕当前位置建立连续目标表达和独立测试，再进行安全的实机验证。
2. **普通 MOVE 缺少执行生命周期。** ROS 只有目标 topic，无法区分发布、控制器接受、开始执行、到位、
   超时和中止；正常 FIFO 可接受积压命令。后续应单独设计执行确认与运动所有权。
3. **夹爪串口与状态。** 当前没有位置/力反馈、独占打开、完整失联重连及显式串口关闭流程。
   补足串口资源管理和 ACK 状态接口应独立验证，不能把 `OK SET` 当作真实夹持反馈。
4. **机械参数/模型来源。** 实际限位、惯量、负载、固件与 CAD 许可材料不完整。
   `tag0_ref`、历史 TCP 表和标定文件属于特定装配，不能自动成为新机器的配置。
5. **启动权限（第二阶段已修复）。** 见以下迁移记录，不再保留旧危险默认。

## 2026-09-21：显式硬件 opt-in

用户授权最小安全修正：裸 arm `use_mock` 从 false 改 true，`allow_motion_commands`
从 true 改 false；Console/相机包装/canonical launch 同步。`arm_feedback_safe` 与旧
Astra preview 固定关闭运动许可。原 real 行为需 `use_mock=false` + `allow_motion_commands=true`。
夹爪新增 `allow_hardware_actuation=false`，在串口构造前退出；callback/send 也拒绝，
显式 true 恢复原 PING/PONG 和 SET/ACK。没有模拟位置、夹持或控制器成功反馈。

这是有意的启动契约变更，旧启动命令须迁移；协议字节、映射、PWM、关节/TF/标定均保留。
构造级 fake、协议回归和 launch 参数检查在离线运行；实体运动复验为
`SKIPPED: requires physical robot actuation`。详见 [bringup.md](bringup.md)。

## 验证如何记账

构建、语法/依赖检查、mock/PTY、几何测试、合成规划与实体运动分别记录。
本轮开源整理没有启动实体驱动、发送六轴/夹爪命令或修改控制器固件。
实机检查仍需覆盖：每轴方向与限位、J6 线缆范围、STOP/DISABLE/失联、夹爪脉宽及受力、
TCP 和手眼外参精度、抓取/抬升/返回各阶段。
历史日志、历史测试通过或文档中的示例值都不能直接填写为本轮“实机通过”。
