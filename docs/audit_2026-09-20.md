## B. Architecture

完整 Mermaid、node/topic/service/TF/parameter 说明见 [architecture](architecture.md)。核心链：

- Console/CLI → `/arm/joint_command` → driver 校验和 ideal/raw 映射 → START/串口 MOVE → 控制器；没有 FollowJointTrajectory 硬件 action。
- 控制器 GETJPOS → driver → `/arm/raw_joint_states` 与 `/joint_states` → robot_state_publisher → TF → RViz/规划；当前仅六轴，passive TCP 常规发布者缺失。
- `/gripper/pulse_us` → gripper serial → MCU SET/ACK；仓内无固件，只能确认 ESP32/PCA9685 协议，S3 型号/接线待确认，无夹持反馈。
- RGB-D/点云 → 同步/反投影/采集时刻 TF → 平面/聚类/OBB → 短轴候选 → 私有 MoveIt IK/碰撞/路径 → RViz；硬拒 `dry_run=false`，没有执行客户端。
- 旧 AprilTag/双相机 target selection/手眼工具独立保留；不是完整点云融合，也不等同新抓取链。
- 移动底盘尚无实现；当前 `base_link` 已有机械臂含义。没有伪造 `map→odom` 或重命名机械臂 frame。

多数串口、波特率、camera/topic/frame、速度和 launch 开关已参数化。硬编码分为：
可配置设备默认（公开副本替换身份）、现场配置（留本机）、机械契约（本轮不更改），避免重复造配置层。
