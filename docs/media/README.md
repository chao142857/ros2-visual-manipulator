# Demo 素材

当前没有获准公开的整机照片、实物抓取视频或底盘演示。本目录只记录素材要求，不伪造 demo。

后续可加入：整机与模块标注照片、ROS/RViz 规划录屏、受监督的单次实物实验录像。
每份素材注明日期、软件版本、硬件版本、操作范围和结果；合成/mock/规划显示必须清楚标记，
不能标作实物执行或自主移动操作。拍摄者授权、第三方模型许可、现场隐私应先确认。

较大视频通过经过授权的外部演示链接提供，避免把原始录制、rosbag 或实验数据直接加入 Git。
失败演示可公开记录，但不从画面或 ACK 推断夹持力、标定精度或安全验收。

当前软件演示入口见 [README](../../README.md#quick-start)，媒体发布策略见
[assets](../../assets/README.md) 与 [第三方材料](../../THIRD_PARTY_NOTICES.md)。
